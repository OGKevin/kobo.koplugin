# Swap Page-Turn Buttons When Inverted

## Overview

The "Swap page-turn buttons when screen is inverted" setting reverses the next-page and
previous-page buttons of a Bluetooth remote while the screen is rotated by 180 degrees.

## Default Behavior

- **Default**: Disabled
- **Location**: Settings → Network → Bluetooth → Settings → Swap page-turn buttons when screen is
  inverted

## How It Works

For a remote that is attached to the reader, for example built into a case, turning the reader
around to hold it in the other hand also flips the remote: the upper button becomes the lower one.
With this setting enabled, the actions bound to next page and previous page are swapped whenever the
screen is in upside-down portrait or inverted landscape rotation, so the upper button keeps turning
the page the same way.

The setting applies to all Bluetooth remotes and only to the page-turn actions. Combined with a
button bound to "Invert rotation", switching hands takes one press.
